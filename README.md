## 同为 2 核 4G，价格差在哪里

答案在 CPU 代际、磁盘规格和机房带宽成本，三项叠起来能拉开近一倍。EPYC 7763 入门 Mini 是 $39/月，香港 Pulse Mini $59/月，Peak X5 Mini $59/月，Turin.Mini $69/月。四台机器内存都是 4GB，选哪个取决于你跑什么。

第三方在 2025 年 8 月对香港这两条线做过实测，数据能说明不少问题。同样是 2 核 4GB 的 HKG.Peak.X5.Mini（Ryzen 9 9950X），Geekbench 6 单核 **3419**、多核 5974；HKG.Pulse.Mini（EPYC 7763）同期成绩是单核 1537、多核 2798。单核差了一倍多，PassMark CPU Mark 也差了一半（8451 对 4307），内存延迟 65ns 对 58ns 则基本持平。

但磁盘是反向的。Pulse Mini 的 fio 大块顺序读写能到 1.20 GB/s 和 1.28 GB/s，Peak X5 Mini 在 1m 块下只有 561 MB/s 和 598 MB/s。测评者的判断是 X5 相比 7763 系列限制了 IO，差不多砍半。所以：

- 跑 MySQL InnoDB、Redis、编译构建、需要单核高频的业务 → 优先 Peak X5 或 Turin，CPU 差距肉眼可见
- 跑对象存储代理、大文件分发、备份转储这类吃磁盘吞吐的活 → Pulse 线的大块 IO 反而更合适
- 只是搭个静态站、挂反向代理、跑个小 API → $39 的 EPYC 入门档够用，多花的钱买的是余量，不是体感

需要装 Windows 的话，Turin 的 Pro / Ultra 和日本 Pulse 的 Pro / Ultra 都标了支持，别在最低档上自己折腾驱动。

## 海外VPS测评里最容易被跳过的一页：退款与到期规则

GoMami 提供 24 小时无风险取消，服务激活后 24 小时内不满意可申请全额退款。这句话本身没问题，但完整规则比它复杂得多，而且这些细则才真正决定你敢不敢下单。

**能退的前提**：新购买的实例、每用户限一次、退款退回原支付方式。申请路径是提交工单选 Billing 分类，说明理由后等客服处理。到账时间分渠道：支付宝 1–3 个工作日，信用卡 5–10 个工作日，加密货币 1–3 个工作日。

**不能退的情况**，逐条列出来比一句宣传语有用：

- 超过 24 小时的订单，续费订单同样不适用
- 用加密货币或其他数字资产支付的订单属于最终交易，即使还在 24 小时内也不退
- 24 小时内单台 VM 流量使用超过 **10GB**
- 因违反服务条款被终止的服务，包括故意超量消耗带宽、CPU 时间或磁盘 IO
- 因 DDoS 攻击被黑洞的 IP
- 已使用的账户余额
- 所分配 IP 在 RIPE Atlas 活跃锚点少于 3 个的地区无法正常使用时

还有一条容易被忽略：退款获批后，对应服务器实例和数据会立即永久删除，不受任何申诉期保护。申请前先把需要的东西拉下来。

> 24 小时窗口实际只够做一件事：开机、跑一遍线路测试、确认延迟和丢包能不能接受。把它当“免费用两天”的工具，10GB 流量红线会先拦住你。

**到期这件事没有缓冲。** 到期当天服务立即暂停、数据保留，付款后自动恢复；逾期 5 天服务终止，数据可能无法恢复。官方在账单说明里写得很明确：到期即暂停，没有宽限期。打算长期用的话，提前充值余额自动续费，或者到期前主动取消——路径是 Services > My Services 里选服务，点 Request Cancellation，再选 Immediate 或 End of Term。

**关于备份，官方口径内部是打架的。** 第三方资料提到 GoMami 提供每日自动备份至 AWS S3；但官方服务条款明确写着不为客户账户做数据备份、不对数据丢失负责，建议客户自行定期备份。两句话放在一起，结论只能是：真出问题的时候能指望的只有你自己的备份。退款会删数据、逾期会删数据、条款不兜底，这三件事指向同一个动作。

## 线路到底怎么样：先用 Looking Glass 自己测

官方宣称中国大陆方向 RTT 低于 50ms，电信、联通、移动三网优化。这是厂商口径，不是跨运营商实测，看的时候心里打个折。

按产品线的路由结构，香港、日本、新加坡三地是去程电信 163 / 联通 10099 / 移动 CMI，回程走 CN2 / 9929 / CMIN2；洛杉矶则是三网双向高端。亚洲节点胜在回程质量，洛杉矶胜在双向一致。第三方在 2025 年的测评里也提到，Peak 和 Pulse 两条线在售卖页标注的是 “China Mainland Optimized Pro”，具体回程走向以实际路由追踪为准，不同批次可能调整。

下单前的验证工具是官方的 Looking Glass，支持 Ping、TCPing、MTR、NextTrace、Traceroute 五种测试。从你所在的城市和自己的运营商去 ping 一遍，看晚高峰时段的丢包，比看任何测评文章都准。同一个机房，广东电信和四川移动的结论可能完全相反，别人的测试数据对你只有参考价值。

DDoS 防护方面，默认是 Best-Effort 级别，需要更强清洗可以单独购买，最高 600 Gbps 能力。这层保护和退款条款挂钩：IP 因 DDoS 被黑洞，不在退款范围内。

上手流程本身不复杂：注册账户、选套餐和节点、通过 SSH 连上、开始部署，四步走完。官方提供 RESTful API，可以编程管理账户和服务器；控制面板能实时看 CPU、内存和网络流量；KVM 虚拟化，装系统不额外收费。需要自己重装或换系统的，这些是日常会用到的。

## 下单前常问的几个问题

**支持哪些付款方式？** 信用卡和借记卡（Stripe）、支付宝（Stripe Alipay）、加密货币。国内用户走支付宝最省事，但记得加密货币付款不可退款。

**能开企业发票或走对公吗？** 官方文档只提到支付方式与退款流程，企业采购建议先开工单确认，别默认可以。

**买完发现线路不合适怎么办？** 24 小时内提交 Billing 工单申请退款，前提是首购、非加密币支付、流量没超 10GB、IP 没被 DDoS 黑洞。这条决定了你的测试必须在开机后头几个小时做完。

**能把机器从日本换到香港吗？** 续费时可以更换计费周期，跨机房迁移没有公开说明，需要联系客服确认，不要默认可以随意搬。

**流量用完之后会怎样？** 目前公开资料里没有写明是限速、停机还是额外计费，下单前建议在工单里问清楚，或者按最保守的假设做容量规划。
